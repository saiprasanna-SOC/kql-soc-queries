KQL SOC Queries
Overview

This repository contains Kusto Query Language (KQL) queries developed for Security Operations Center (SOC) monitoring, threat detection, investigation, and threat hunting.

The queries focus on common SOC activities such as authentication analysis, endpoint investigation, phishing detection, Conditional Access monitoring, and suspicious network activity.

Areas Covered
Authentication monitoring
Failed login investigation
Successful login analysis
Suspicious sign-in detection
Endpoint investigation
PowerShell activity
Suspicious process detection
Phishing investigation
Conditional Access monitoring
Threat hunting
Suspicious IP investigation
